Architecture

中继节点组织结构

彩虹云将数据通道划分为分级调度集群，依照用户签约的订阅层级提供相匹配的出口路由策略与带宽分配标准。

普通线路节点池

分配于标准接入层。主要处理通用网页浏览、静态资源中继与基础数据同步请求，提供基础流媒体解析服务，保障常规链路连通。

IPLC 专线优化层

针对要求低抖动、低丢包率的交互式网络流量设立。通过专用通道直连关键网络出口，适合网络游戏、实时音频协作与原生内容识别。

VIP 专享带宽池

为高并发流量业务设立的独立通道。支持端到端路由规则定制，具备冗余带宽储备，保障团队协作与大容量文件调度的稳定性。

Operations

客户端标准配置步骤

完成订阅获取后，请遵循三步标准流程进行客户端链路下发与规则更新。

PHASE 01

获取订阅 URI 凭证

在个人用户中枢复制分配给该账号的专用订阅 URL。请妥善保存此令牌，防止链接外泄导致并发设备数被异常占用。

PHASE 02

写入通用核心客户端

启动本地支持的代理转发工具，在“配置/订阅”入口粘贴 URI 链接，执行远程拉取，确认节点列表成功解包并列出。

PHASE 03

定义路由与策略分流

将路由模式调整为“规则分流”或指定代理组。发起单次链路延迟探测，选取响应状态良好的入口启动本地中继进程。

Compatibility

客户端支持规范

彩虹云输出通用订阅格式，不绑定单一闭源程序，支持各平台遵循标准网络转发规范的第三方客户端。

Windows 系统

适配 Clash Verge、Clash for Windows 等图形化客户端，支持系统全局代理注入与 TUN 虚拟网卡模式。

macOS 系统

支持 ClashX、Clash Verge rev 及 Surge 系列核心。配合系统网络扩展模块，实现按应用程序分流。

iOS / iPadOS

支持导入 Shadowrocket、Quantumult X 及 Loon 等具备规则引擎的第三方应用进行节点同步。

Android 系统

兼容 Clash for Android 及 Surfboard，可调用系统的 VpnService 接口实现开机自启与后台保活。

Technical Reference

常见技术问题解答

以下整理了关于账户配额、多设备连接以及链路状态相关的基础操作指南。

如何界定“同时在线设备数”的计算逻辑？

系统以同一时刻向中继节点发送连接握手请求的独立公网 IP 及客户端指纹进行统计。若在线设备总数超出订阅限额（例如基础版超过 3 台），超出部分连接将被重置。

流量配额的重置周期是如何设定的？

配额遵循订单周期的账单日重置机制。例如在当月 15 日订购，流量将于次月 15 日自动归零并重新计算，不可顺延至下一计费周期。

订阅链接无法更新或提示解析失败如何处置？

通常是由于本地客户端网络直接请求受限或 DNS 污染所致。可在客户端中切换“跳过证书验证”进行尝试，或更换本地 DNS 为通用解析服务器后重新拉取。

旗舰版与团队版的 IPLC 节点有何技术差异？

旗舰版 IPLC 节点主要针对个人娱乐、主流流媒体及游戏端口优化；团队版则在此基础上部署独立网关，并支持根据机构出口需求指定白名单与路由路径。

是否可以随时升级现有的订阅套餐？

支持按剩余天数折算补足差价升级至更高规格方案。升级生效后，月度流量限额与并发设备数将即时刷新为新方案基准。

节点出现不可用状态时的排查规范？

首先请在客户端内执行配置强制更新，以同步最新后端节点 IP 与端口；其次确认本地系统时间与网络授时服务器误差在 60 秒以内。
